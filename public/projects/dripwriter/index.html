02 the useful boundary

A tiny bridge between a prepared sentence and the right input.

Dripwriter is deliberately boring about the risky parts. You choose the tab, you see the target, and the run ends when the text is done.

03 one run

Three decisions. One visible result.

A

Keep the sentence

Write in the local editor or pull in a saved snippet. Your library stays encrypted and close.

local library
B

Arm the field

Place the caret, pair the browser companion, and confirm the exact tab before anything runs.

explicit target
C

Let it finish

Typing, waits, selected keys, and repeats happen in a finite sequence you can pause or stop.

bounded workflow

04 underneath

Useful automation with the edges left on.

Swift on macOS, a local Manifest V3 companion, AES-GCM library storage, Keychain pairing, and no page-content access. The product is the restraint.
